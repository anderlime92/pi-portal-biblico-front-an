Integração PHP

Pronto para virar Tema WordPress

O script embutido aceita dinamicamente vetores de URLs vindas diretamente do banco de dados do seu WordPress via PHP (`wp_localize_script` ou variáveis inline no `footer.php`).

  • Compatível com ACF (Advanced Custom Fields)
  • Totalmente responsivo e mobile-friendly
  • Sem dependências externas além do Bootstrap 5
<!-- Exemplo WordPress PHP -->
<?php
  $backgrounds = get_field('galeria_fundos');
  $urls = array_column($backgrounds, 'url');
?>
<script>
  const bgArray = <?php echo json_encode($urls); ?>;
</script>
